<section class="q-section">
  <h2 class="q-h2" style="margin-bottom:16px;">Reproducibility</h2>
  <p style="font-size:15px;color:var(--sub);margin:0 0 4px;">We commit to the following for every released repo:</p>
  <ul class="q-checklist">
    <li class="done">Pinned dependencies · requirements.txt or environment.yml</li>
    <li class="done">Single-command training entrypoint · scripts/train.sh</li>
    <li class="done">Single-command evaluation · scripts/eval.sh</li>
    <li class="done">Pre-trained checkpoints when license permits</li>
    <li class="done">Dataset DOI or download script</li>
    <li class="pending">Hardware &amp; wall-clock from the paper (partial)</li>
    <li class="pending">Hyperparameter search logs (partial)</li>
  </ul>
  <p style="margin-top:20px;font-size:13px;color:var(--sub);">
    Issues for missing artifacts: file at <a href="https://github.com/UMN-Choi-Lab" style="color:var(--accent);font-weight:600;">github.com/UMN-Choi-Lab</a>/&lt;repo&gt;/issues — tag with <strong style="color:var(--accent);">repro</strong>.
  </p>
</section>
